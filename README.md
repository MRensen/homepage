# HomePage for Mark Rensen

This is a side-project about me and the things I do.

I'm a fullstack developer with a strong preference for backend, so the design of this homepage reflects that.
It is designed to look and feel like a terminal interface. 
My intention is to implement a various of well-known terminal operations to serve a purpose for my homepage.

## Terminal features
- `clear` and `home` clear the screen.
- `ls` shows a list of documents you can view
- `help` shows a list of all command you can do.
- `neofetch` shows my personal information in a neofetch style.
